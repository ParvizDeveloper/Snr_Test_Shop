#  Prnoia Store - витрина товаров с корзиной и чекаутом

Тестовое задание: витрина товаров на Next.js с корзиной и оформлением заказа. Данные о товарах берутся из (https://fakestoreapi.com/).

## Стек

- **Next.js 14** (Pages Router) - обычный `.js`/`.jsx`
- **React Context + localStorage** - состояние корзины сохраняется между визитами
- **CSS Modules** - тёмно-синяя/чёрная/белая палитра
- **FakeStore API** - `https://fakestoreapi.com`

## Как запустить

```bash
npm i
npm run dev
```

Открыть http://localhost:3000

## Что реализовано

- Загрузка товаров с публичного API (`getStaticProps` / `getStaticPaths`,
  ISR с `revalidate`, есть обработка ошибок сети)
- Фильтрация каталога по категориям
- Добавление в корзину прямо из каталога и со страницы товара (с выбором
  количества)
- Корзина: изменение количества, удаление товаров, подсчёт итоговой суммы
- Чекаут: форма с данными доставки и оплаты, валидация полей на клиенте,
  экран успешного оформления заказа с номером заказа
- Корзина сохраняется в `localStorage`, переживает перезагрузку страницы
- Адаптивная вёрстка
